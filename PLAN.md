# Fancy Game – Plan

- [x] Phase 1: Foundation (scaffold, lint, tests, CI)
- [ ] Phase 2: Core loop (lanes, scrolling street, collision, score, game over)
- [ ] Phase 3: Traffic system (rickshaws, buses, scooters, cows; spawner and difficulty)
- [ ] Phase 4: Funny layer (random events, captions, horns)
- [ ] Phase 5: Polish (parallax, sound, menu, touch controls)
- [ ] Phase 6: Release (e2e smoke, deploy)
